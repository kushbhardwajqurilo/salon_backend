# Unisex Parlour ERP — Technical Documentation Set

This directory contains the eight companion technical specifications for the ERP architecture.

1. `PERMISSIONS.md` — Permission registry and RBAC.
2. `API_CONTRACT.md` — Frontend/backend API conventions.
3. `AUTHENTICATION.md` — Authentication and session lifecycle.
4. `DATABASE_ARCHITECTURE.md` — Data ownership, organization and branch semantics.
5. `FRONTEND_ARCHITECTURE.md` — Next.js frontend engineering rules.
6. `BACKEND_ARCHITECTURE.md` — Express/MongoDB backend engineering rules.
7. `TESTING_STRATEGY.md` — Functional and security testing.
8. `DEVELOPMENT_WORKFLOW.md` — Standard domain implementation workflow.

`ARCHITECTURE.md` remains the parent high-level architecture document. These files provide detailed technical guidance beneath it.
